# Local Governance Hubs

Computational resources for *Computational Modeling and Spatial Arrangements in Solid Waste Management: Strategies for Energy Recovery and Decision-Making*. This repository provides R scripts, input datasets, and computational procedures to support reproducible research, spatial analysis, computational modeling, the assessment of local governance hubs, and the investigation of energy recovery strategies in solid waste management.

The repository is organized as an RStudio project (`LocalGovernanceHubs.Rproj`) and includes resources for data preparation, spatial analysis, computational modeling, and the generation of analytical outputs, maps, tables, and figures.

For reproducibility, please use the R scripts and datasets provided in this repository, following the corresponding computational workflow and documented dependencies.

This repository contains the R scripts and computational resources developed to support the research presented in the manuscript:
*Computational Modeling and Spatial Arrangements in Solid Waste Management: Strategies for Energy Recovery and Decision-Making.*
